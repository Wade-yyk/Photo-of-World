METHOD, INTERACTION, AND OPTIONAL FEATURES

Split. Search. Refine.

1 / Channel extraction. Each vertical plate contains three grayscale exposures: blue at the top, green in the middle, and red at the bottom. The core split uses height = gray.shape[0] // 3 and takes the three consecutive sections. Grayscale is appropriate because each exposure is a single-channel luminance record captured through a separate colour filter.

2 / Baseline NCC alignment. Blue is the reference channel. Green and red are translated independently until their match score is largest. For a recorded shift such as G = (+1, +1), green moves one pixel right and one pixel down.

NCC(A, B) = Σ[(A − Ā)(B − B̄)] / √[Σ(A − Ā)² · Σ(B − B̄)²]

Before scoring, the current baseline ignores 10% of each edge and uses only valid overlap. The 10% edge exclusion is a scoring safeguard; automatic cropping is a separate optional feature below.

3 / Single-scale alignment. This implementation uses a reduced single-scale baseline for large scans: channels are capped at a longest side of 400 pixels, while smaller plates stay at their native size. It then tests every integer shift in a ±15-pixel window and keeps the highest NCC score. The 400-pixel cap is an engineering choice for a quick comparison, not a requirement of the assignment; a full-resolution single-scale search would be slower and would need a wider window for large displacements.

4 / Coarse-to-fine pyramid. Large channels are repeatedly smoothed and downsampled by two until the longest side is at most 192 pixels. The smallest level searches ±15 pixels. At each finer level, the previous offset is doubled and refined in a ±2-pixel window. The loop is equivalent to while max(refs[-1].shape) > coarse_size: refs.append(downsample(refs[-1])).

5 / Common valid canvas. After translation, only the rectangle shared by B, G, and R is retained. Its bounds use x0 = max(dx), x1 = min(width + dx), y0 = max(dy), and y1 = min(height + dy) across the three offsets. This removes missing pixels caused by displacement.

OPTIONAL FEATURES

What the switches do

Gradient alignment

Instead of comparing raw intensity, compare image structure with E(x,y) = √(Ix² + Iy²). The implementation uses gy, gx = np.gradient(smooth) and magnitude = np.hypot(gx, gy).

Automatic cropping

The image is reduced to at most 900 pixels, all four edges are inspected, and the detector looks for brightness transitions, near-black or near-white borders, and unusual channel differences. It searches for the transition from border to real picture instead of removing a fixed margin. A similar border colour or a large white sky can still confuse the detector.

Automatic contrast

Use the 1st and 99th percentiles of the interior: lo, hi = np.percentile(region, (1, 99)), then result = clip((image − lo) / (hi − lo), 0, 1). The same mapping is applied to all three channels.

Gray-world white balance

Assume the average colour is close to gray. With channel means means, use gains = means.mean() / means and balanced = image * gains. A scene dominated by grass, sky, or a red wall may be overcorrected.

Experimental colour mapping

Use M = 0.85I + 0.15L, where every row of L is [0.2126, 0.7152, 0.0722]. This retains 85% of the original colour, adds 15% luminance, slightly reduces intense colours, and keeps neutral gray close to neutral. It is an experimental visual mapping, not calibrated historical colour recovery.

Feature toggles

Each photograph has independent switches. All are off by default, so the original pyramid NCC result is preserved. The page can combine the five effects and reset any image to the baseline.
